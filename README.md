# ACST 研究归档

《刺客信条：影》存档和引擎研究的工具、文档与样本。

- `acst.md`：研究记录
- `GAME-RESEARCH-PLAYBOOK.md`：研究方法
- `artifacts/`：地址、类型和反编译文本；见 `artifacts/README.md`
- `tools/`：研究与 Ghidra 工具
- `saveparse/`：存档解析器及七份样本
- `ini-presets/` 与 `ini-*.sh`：配置预设和辅助脚本
游戏二进制、Ghidra 项目和完整存档备份不在此仓库。历史文档中的路径和状态以记录当时为准；运行脚本前请检查本机路径及操作内容。
